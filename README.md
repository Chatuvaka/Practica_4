# Checador Inteligente

Sistema de asistencia desarrollado con React Native, Expo y Supabase.

El proyecto está compuesto por dos aplicaciones:

- Mobile: aplicación de registro de asistencia mediante biometría.
- Display: pantalla inteligente que muestra avisos y reacciona en tiempo real a entradas y salidas.

## Tecnologías

- React Native
- Expo
- Expo Router
- TypeScript
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Realtime
- expo-local-authentication
- AsyncStorage
